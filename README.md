### Завдання № 10.2 (Рівень А та Рівень В): Багатомодульне впорядкування та бінарний пошук

Обидва рівні (`Lab_10_2_A` та `Lab_10_2_B`) організовано як **багатомодульні проєкти** без глобальних змінних із строгим рядковим контролем введення (`ReadInt`, `ReadDouble` з підтримкою крапки й коми, `ReadLine`), текстовим меню (`[1]` автоматичне виконання всіх дій, `[2]` ручне введення, `[3]` фізичне впорядкування, `[4]` індексне впорядкування та вивід, `[5]` ручний бінарний пошук):
- `student.h` / `student.cpp` — типи даних (`Specialnist`, `Student`), автогенерація, валідація введення, обчислення середнього балу та табличний вивід.
- `sort_search.h` / `sort_search.cpp` — компаратори ключів (`CompareAvg` з `eps = 0.05`, `CompareKeys`), фізичне сортування бульбашкою (`Sort`), індексне сортування вставками (`IndexSort`, `PrintIndexSorted`), бінарний пошук (`BinSearch`).
- `Lab_10_2_A.cpp` / `Lab_10_2_B.cpp` — головний модуль (`main`, `RunAllAuto`).
- Ключі сортування та пошуку (Варіант 23): назва спеціальності ↑ (транслітерація) → середній бал ↑ → прізвище ↑.
