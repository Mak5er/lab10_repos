## Опис завдань (Варіант 23)

### Завдання № 10.1 (Рівень А та Рівень В): Послідовний пошук в масиві структур
- **Рівень А (`Lab_10_1_A`):** динамічний масив структур `Student` (прізвище, курс, спеціальність як `enum`, оцінки з фізики, математики, інформатики), вивід у вигляді 7-стовпцевої таблиці.
- **Рівень В (`Lab_10_1_B`):** динамічний масив структур з анонімним об’єднанням `union` для профільної третьої оцінки (програмування для `KN`, чисельні методи для `INF`, педагогіка для `ME`, `FI`, `TN`), вивід у вигляді 9-стовпцевої таблиці.
- **Опрацювання (Варіант 23):**
  1. Вивести прізвища студентів, які вчаться без трійок (на «відмінно» і «добре»).
  2. Обчислити кількість студентів, які отримали з фізики оцінку «5».

### Завдання № 10.2 (Рівень А та Рівень В): Впорядкування та бінарний пошук в масиві структур
- **Рівень А (`Lab_10_2_A`)** та **Рівень В (`Lab_10_2_B`)** із текстовим меню та контролем помилок введення:
  1. Фізичне впорядкування масиву (`Sort`): за назвою спеціальності ↑, далі за середнім балом ↑, далі за прізвищем за зростанням ↑ (український алфавіт).
  2. Індексне впорядкування (`IndexSort`, `PrintIndexSorted`) за тими самими ключами без зміни основного масиву.
  3. Бінарний пошук (`BinSearch`) студента за вказаною спеціальністю, середнім балом і прізвищем.

### Завдання № 10.3: Опрацювання масиву структур (Готель)
- Модель готелю з 15 номерів: номери `1..5` — одномісні, номери `6..15` — двомісні.
- Динамічний масив структур `Resident` із текстовим меню, контролем місткості номерів, додаванням, вилученням, редагуванням записів, записом та зчитуванням у бінарний файл (`<fstream>`, `ios::binary`).
- Пошук номера помешкання за прізвищем мешканця (обробка 0, 1 та >= 2 збігів із додатковим запитом ініціалів).
